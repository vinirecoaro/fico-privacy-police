Termos de Uso e Política de Privacidade

Ao utilizar o aplicativo FICO – Financial Control, o usuário declara estar ciente e de acordo com os termos e condições descritos neste documento.

1. Coleta de Dados

O aplicativo coleta informações fornecidas diretamente pelo usuário, como registros de despesas, receitas, categorias financeiras e demais dados necessários para o controle financeiro pessoal.

Também podem ser coletadas informações técnicas, como dados de uso do aplicativo e informações do dispositivo, exclusivamente para garantir o correto funcionamento e melhoria da experiência do usuário.

2. Armazenamento e Processamento dos Dados

Os dados do usuário são armazenados de forma segura em serviços de computação em nuvem fornecidos pelo Google, como o Firebase Realtime Database, sendo utilizados exclusivamente para o funcionamento das funcionalidades do aplicativo.

3. Finalidade do Tratamento dos Dados

Os dados coletados são utilizados para permitir o funcionamento do aplicativo, organização financeira pessoal, geração de relatórios, sincronização de informações e aprimoramento contínuo das funcionalidades.

4. Segurança das Informações

A transmissão e o armazenamento dos dados são protegidos por medidas de segurança técnicas adequadas, incluindo criptografia durante a transferência das informações e regras de acesso restritas aos dados armazenados.

5. Compartilhamento de Dados

O aplicativo não vende, aluga ou compartilha dados pessoais ou financeiros dos usuários com terceiros. Os dados são acessados apenas pelo próprio usuário e utilizados estritamente para a finalidade do aplicativo.

6. Limitação de Responsabilidade

O aplicativo FICO – Financial Control tem caráter exclusivamente informativo e organizacional, não constituindo aconselhamento financeiro, contábil, jurídico ou de investimentos.

O desenvolvedor não se responsabiliza por decisões tomadas com base nas informações fornecidas pelo aplicativo.

7. Base Legal para o Tratamento

O tratamento dos dados pessoais ocorre com base no consentimento do usuário e na execução das funcionalidades oferecidas pelo aplicativo, conforme a legislação vigente de proteção de dados.

8. Exclusão de Dados

O usuário pode solicitar a exclusão definitiva de seus dados pessoais e financeiros a qualquer momento, por meio do e-mail de contato informado neste documento. Após a solicitação, os dados serão removidos permanentemente dos servidores.

9. Retenção dos Dados

Os dados são mantidos apenas pelo tempo necessário para o funcionamento do aplicativo ou até que o usuário solicite sua exclusão, salvo quando houver obrigação legal de retenção.

10. Alterações nos Termos

Este documento poderá ser atualizado periodicamente para refletir alterações legais ou melhorias no aplicativo. Recomenda-se a revisão regular desta política.

11. Contato

Em caso de dúvidas ou solicitações relacionadas a estes Termos de Uso e Política de Privacidade, entre em contato pelo e-mail: finantial.control.app@gmail.com
